## Description

Cuando varios agentes trabajan en paralelo sobre el mismo repo/board, dos pueden reclamar la misma tarea. Agregar lock exclusivo: `task_claim` fija `lockedBy` + `lockedAt`, otros agentes ven el lock y no pueden reclamar hasta que se libere (task_release o expiración por timeout).

Es diferenciador real frente a TODO.md: coordinación segura multi-agente.

## Acceptance criteria

- [ ] Campo lockedBy y lockedAt en frontmatter de tarea (opcional)
- [ ] task_claim marca lockedBy=agent y rechaza claims si ya está bloqueada por otro agente activo
- [ ] Expiración automática del lock tras N minutos sin heartbeat (default 30m) para evitar deadlocks
- [ ] UI: candado visual en TaskCard y TaskModal con quién lo tiene
- [ ] Tool MCP task_release para liberar un lock manualmente
- [ ] Tests de contención: dos claims simultáneos, solo uno gana
