## Description

Escanear el `git log` del proyecto buscando referencias a IDs de tarea (ej. `TK-12`, `AS-3`) en los mensajes de commit y en nombres de rama, y mostrar los commits/PRs enlazados dentro del TaskModal. Esto da trazabilidad automática entre lo planificado y lo implementado sin fricción para el usuario.

Implementación sugerida: nuevo módulo `gitLinks.ts` en core (spawn `git log --grep`, `git branch --contains`), endpoint `GET /api/tasks/:id/commits` en server, sección "Linked commits" en el modal con hash, autor, fecha y mensaje.

## Acceptance criteria

- [x] Módulo core que escanea git log buscando IDs de tarea (regex configurable)
- [x] Endpoint GET /api/tasks/:id/commits que devuelve lista de commits enlazados
- [x] Sección 'Linked commits' en TaskModal con hash corto, autor, fecha y mensaje
- [x] Badge o contador de commits en TaskCard cuando la tarea tiene actividad
- [x] Tests del parser de git log con repos temporales
