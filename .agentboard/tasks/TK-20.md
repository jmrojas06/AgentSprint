## Description

Registro cronológico de todo lo que pasó con cada tarea: quién la creó, cuándo cambió de estado, checklists completados, notas agregadas, commits enlazados. Se muestra como timeline vertical dentro del TaskModal.

A diferencia de las notas libres actuales, esto es un log estructurado machine-readable que también sirve para auditoría y para que los agentes entiendan el historial sin leer diffs.
