## Description

Hoy, con el MCP caído, los subagentes editaron los archivos de tarea a mano: notas con formatos distintos (`- [ISO] (autor)` vs `- ISO | autor |`), horas de actividad imposibles (eventos antes de crear la tarea), criterios marcados sin evento y locks que nadie tomó. El board necesita un camino seguro por línea de comandos que use el mismo core (locks, actividad, saneado) que el MCP.

## Acceptance criteria

- [x] `agentboard task <claim|release|status|note|check|review|show> <dir> <id> …` con `--agent <name>` (actor de la actividad); usan los mismos métodos de ProjectStore que las herramientas MCP (lock en claim, actividad, sanitizeActor)
- [x] `show` imprime la spec (`task_spec`) o `--json`; `check` marca un criterio por índice o texto; `review` acepta `--verdict approve|changes --finding … --summary …`
- [x] El protocolo que se añade a cada subagente en `.claude/agents/` (subagents.ts) dice: si las herramientas agentsprint no están disponibles, usa `agentboard task …` y nunca edites a mano el frontmatter ni la actividad
- [x] Tests de CLI para cada subcomando (incluido un claim con lock activo de otro agente) y docs/cli.md actualizado
