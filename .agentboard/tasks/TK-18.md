## Description

Bajar la barrera de adopción permitiendo importar trabajo existente al board:
1. `agentboard import todo [archivo]` — parsea un TODO.md / NOTES.md con bullets o checkboxes y crea tareas.
2. `agentboard import github <owner/repo>` — importa issues abiertas usando `gh issue list` (opcional, requiere gh instalado).

Cada tarea importada queda marcada con un tag de origen (ej. `imported:todo`) y se puede filtrar. Esto hace trivial migrar desde cualquier flujo basado en texto.

## Acceptance criteria

- [ ] Comando agentboard import todo <archivo> que convierte bullets/checkboxes en tareas
- [ ] Comando agentboard import github <owner/repo> que importa issues abiertas vía gh CLI si está disponible
- [ ] Mapeo configurable de labels a tags y milestones a sprints
- [ ] Detección de duplicados por título similar antes de crear
- [ ] Reporte de importación: N creadas, M omitidas por duplicado
- [ ] Tests del parser TODO.md con archivos fixture
