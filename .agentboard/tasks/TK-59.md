## Description

Hallazgo del code-reviewer en TK-56: el contenedor Docker, con un build anterior, regenera `.claude/agents/*.md` en cada cambio del board (packages/server/src/projects.ts) y devolvió los 9 subagentes al protocolo viejo ("edita el archivo de la tarea a mano") minutos después de que el CLI nuevo los actualizara. Con varios procesos de AgentSprint de versiones distintas sobre el mismo repo (Docker, MCP stdio, serve local), el último que escribe gana aunque sea el más antiguo.

## Acceptance criteria

- [x] Cada archivo generado lleva en su marcador `agentsprint:generated` la versión del protocolo/plantilla que lo generó (p. ej. un número de esquema que se incrementa al cambiar el texto del protocolo)
- [x] syncClaudeSubagents no sobrescribe un archivo generado por un esquema más nuevo que el suyo: lo deja y devuelve un aviso (`skipped: newer generator`) que el servidor registra una vez
- [x] Los archivos sin número de esquema (generados antes de este cambio) se tratan como esquema 0 y se actualizan; los escritos a mano siguen sin tocarse
- [x] Tests: un generador viejo no degrada uno nuevo, uno nuevo actualiza uno viejo, y doctor avisa cuando hay subagentes de un esquema más nuevo que el binario que corre

- [2026-10-21T22:38:37.553Z] (code-reviewer) **Review: approved** — The guard is correct. subagentSchema returns null for a file without the marker (hand-written, so it is skipped and never removed), 0 for an unstamped generated file (rewritten to schema=1) and N for schema=N. A file with N > SUBAGENT_SCHEMA is neither written nor removed and is reported as 'skipped: newer generator'. projects.ts logs each skip line once per root while it persists. doctor warns about newer files. Tests cover no downgrade, no removal, the schema-0 upgrade and the doctor warning. SUBAGENT_SCHEMA does not need a bump in this wave: no released binary writes schema=1, and every older release (the Docker image included) writes files without a schema, which are schema 0 and get upgraded. Schema 1 just means the protocol as shipped in this release, TK-56/TK-57 text included. Bump it on the next protocol change after this ships. Build, tests, typecheck and lint all exit 0.
