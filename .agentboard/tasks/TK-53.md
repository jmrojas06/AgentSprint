## Description

El flujo Idea → MVP solo existe como prompt MCP (`idea-to-mvp`) y no tiene entrada en la UI (nota del ui-reviewer en TK-37). La UI no llama a un LLM: debe ayudar a escribir la idea y producir el prompt listo para Claude Code, y mostrar el plan cuando las tareas se crean.

## Acceptance criteria

- [x] Un diálogo 'Start from an idea' accesible desde la paleta de comandos y desde el Overview cuando no hay sprint activo o no hay tareas pendientes
- [x] El diálogo pide la idea (y opcionalmente stack y alcance) y genera el texto exacto para Claude Code (`/mcp__agentsprint__idea-to-mvp` con los argumentos) con un botón Copy y otro para la variante CLI
- [x] Explica en una línea qué pasará (un plan de tareas enlazadas que aparecerá en el board en vivo) y enlaza a docs/agents.md
- [x] Foco y Escape siguen el stack de diálogos (`useDialogFocus`); funciona a 375px y 1440px en claro y oscuro; tests del texto generado
