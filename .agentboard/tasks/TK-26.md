## Description

Usar la Notification API del navegador para avisar cuando un agente mueve una tarea a Review ("TK-12 lista para revisión"). Opt-in explícito (botón "Activar notificaciones"), nunca prompt automático.

Valor: el desarrollador trabaja en otra pestaña/ventana mientras los agentes trabajan; se entera al instante cuando debe revisar.

## Acceptance criteria

- [ ] Notificación del navegador (Notification API) cuando cualquier tarea pasa a Review
- [ ] Opt-in explícito con botón/permisos, nunca pedir al cargar
- [ ] Toggle persistente en la UI
- [ ] Click en la notificación abre el board enfocando la tarea
- [ ] Fallback silencioso cuando el navegador no soporta notificaciones
