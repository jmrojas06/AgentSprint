## Description

Comando `agentboard export md` que genera un BOARD.md estático con todo el estado: sprints con stats, tareas agrupadas por columna con sus AC, learnings actuales. Útil para compartir en PRs, wikis, o archivar snapshots del plan en git.

Alternativa futura: export a HTML autocontenido. Empezar por Markdown que es gratis y ya es el formato nativo.

## Acceptance criteria

- [ ] agentboard export md [dir] genera BOARD.md con resumen de sprints y todas las tareas agrupadas por estado
- [ ] Incluye stats por sprint (puntos, % completitud) y sección retro
- [ ] Opción --sprint <id> para exportar solo un sprint
- [ ] Tool MCP export_board devuelve el markdown
- [ ] Test del generador con board temporal
