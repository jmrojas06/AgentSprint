## Description

El review gate deja las tareas en Review con un veredicto, pero el humano tiene que abrir cada archivo o arrastrar tarjetas. Hoy hay 16 tareas esperando. La UI debe permitir cerrar el ciclo: en el Overview y en el modal de tarea, `Mark done` para una tarea en Review, `Request changes` (con hallazgos) que usa `POST /api/tasks/:id/review` con reviewer `user`, y un botón `Close approved (N)` en la sección Waiting for review que mueve a Done todas las que tienen veredicto aprobado más reciente que su último cambio.

## Acceptance criteria

- [x] En Overview, cada fila de Waiting for review tiene una acción `Mark done` accesible por teclado que mueve la tarea a Done sin abrir el modal
- [x] `Request changes` pide los hallazgos (uno por línea, al menos uno) y registra el veredicto con reviewer `user`; la tarea vuelve a In Progress
- [x] `Close approved (N)` solo cuenta tareas cuyo último evento de review es `approved`, pide confirmación y las mueve a Done; el contador se actualiza
- [x] TaskModal muestra el último veredicto (quién, cuándo, resumen) y las mismas acciones cuando la tarea está en Review
- [x] Funciona a 375px y 1440px, en claro y oscuro; tests de componente para las tres acciones
