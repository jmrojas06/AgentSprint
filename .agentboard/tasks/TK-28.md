## Description

Aprovechar el modelo de IA del propio agente para planificar el siguiente sprint: nuevo prompt MCP 'sprint-plan' que recibe contexto (backlog actual, velocity de sprints previos, learnings acumulados) y propone qué tareas incluir, en qué orden, con estimaciones.

El humano revisa la propuesta desde el board y acepta/ajusta. Cierra el círculo del flujo: IA planifica → IA implementa → humano revisa → learnings alimentan el próximo ciclo.

## Acceptance criteria

- [ ] Prompt 'sprint-plan' en el MCP que recibe el goal propuesto y devuelve plan sugerido
- [ ] El prompt incluye: backlog disponible, velocity histórica, learnings y capacidad indicada
- [ ] Tools suficientes para que el agente pueda ejecutar el plan (create_task, update_sprint)
- [ ] Plantilla del plan generada con prioridades, estimaciones y dependencias propuestas
- [ ] Documento docs/sprint-planning.md explicando el flujo completo
- [ ] Test del prompt con board de ejemplo
