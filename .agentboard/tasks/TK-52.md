## Description

Durante la sesión del 2026-10-21 el MCP stdio de Claude Code terminó con código 0 a mitad de trabajo y nadie supo por qué; los subagentes perdieron sus herramientas. Hay que poder diagnosticarlo: registrar la causa de salida y endurecer los casos conocidos.

## Acceptance criteria

- [x] `agentboard mcp` escribe en stderr una línea `[agentboard mcp] exiting: <motivo>` para cada salida: stdin cerrado, señal (SIGTERM/SIGINT/SIGHUP), excepción o rechazo no capturado (con el mensaje)
- [x] Una excepción dentro de una herramienta o del re-sync del board nunca termina el proceso: se devuelve como error de la herramienta (`isError`) y se registra
- [x] Un test arranca el servidor como proceso hijo, hace una llamada, cierra stdin y comprueba el motivo registrado; otro test fuerza un error en el re-sync y comprueba que el proceso sigue vivo
- [x] Reproducción documentada en una nota de la tarea: escrituras concurrentes al board, rebuild de dist y borrado de tareas mientras el MCP corre; si se encuentra la causa del cierre del 2026-10-21, se corrige
