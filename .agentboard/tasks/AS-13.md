## Description

Crear el comando `agentboard lint [dir]` para inspeccionar todos los archivos `.md` y `.yaml`
del board. Detecta errores de sintaxis YAML (como `:` sin comillas en títulos), IDs duplicados,
referencias a sprints inexistentes, dependencias rotas y archivos no parseables.

## Acceptance criteria

- [ ] Comando `agentboard lint [dir]` en el CLI
- [ ] Retorna código 0 si todo está sano, o código 1 con lista detallada de errores
- [ ] Valida sintaxis YAML, formato de IDs, sprints válidos y dependencias válidas
- [ ] Tests en `packages/cli` y `packages/core`
