## Description

Palette de comandos estilo VSCode/Linear (Ctrl/Cmd+K) para navegar el board sin mouse: buscar tarea por ID/título y saltar a ella, cambiar sprint activo, crear tarea, alternar filtros, cambiar tema.

Mejora drástica de velocidad de uso para power users y es un feature muy visible en demos/GIFs para el lanzamiento OSS.

## Acceptance criteria

- [ ] Command palette abrible con Ctrl/Cmd+K
- [ ] Acciones: crear tarea, buscar/cambiar a tarea, cambiar sprint activo, limpiar filtros
- [ ] Búsqueda fuzzy sobre tareas por ID y título
- [ ] Navegación completa por teclado (flechas + Enter + Escape)
- [ ] Componente testeado con render y interacción simulada
