## Description

Soportar plantillas de tareas reutilizables en `.agentboard/templates/*.md`. Una plantilla es un task file con placeholders opcionales (`{{titulo}}`). Casos de uso típicos: reporte de bug, feature spec, tarea de refactor — con AC predefinidas que el agente debe cumplir.

Comando `agentboard task new --template <nombre>` y selector en NewTaskModal + tool MCP.

## Acceptance criteria

- [ ] Directorio .agentboard/templates/ con plantillas Markdown (frontmatter + body)
- [ ] CLI: agentboard task new --template bug-report
- [ ] UI: selector de plantilla en NewTaskModal
- [ ] Tool MCP task_create acepta template como parámetro opcional
- [ ] agentboard init genera 2-3 plantillas de ejemplo (feature, bug, chore)
- [ ] Tests de renderizado de plantillas con variables
