## Description

Soportar plantillas de tareas reutilizables en `.agentboard/templates/*.md`. Una plantilla es un task file con placeholders opcionales (`{{titulo}}`). Casos de uso típicos: reporte de bug, feature spec, tarea de refactor — con AC predefinidas que el agente debe cumplir.

Comando `agentboard task new --template <nombre>` y selector en NewTaskModal + tool MCP.
