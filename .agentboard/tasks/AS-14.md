## Description

Cuando el puerto predeterminado (4310) está ocupado, `agentboard serve` actualmente falla
con `EADDRINUSE`. Mejorar la experiencia buscando automáticamente el siguiente puerto libre
(ej. 4311, 4312) o permitiendo `--port auto` con mensaje claro en consola.

## Acceptance criteria

- [ ] Detección limpia de `EADDRINUSE` con sugerencia o fallback automático
- [ ] Soporte de bandera opcional `--fallback-port` o comportamiento por defecto amigable
- [ ] Mensajes de log claros indicando la URL exacta asignada
- [ ] Tests en `packages/cli`
