## Description

Hallazgo usando AgentSprint sobre sí mismo: `project_context` muestra en "Recent learnings" el volcado del retro de Sprint 5 (`## Tasks`, `### Backlog (0)`, `_none_`…). `learningsTail` parte el archivo por `## ` y solo descarta la sección `## Sprint N retro`; el reporte que el retro incrusta trae sus propios `## Tasks` y `## Retro`, que quedan como secciones sueltas. Arreglo: el escritor anida los encabezados del cuerpo bajo el `## header` del retro, y el lector descarta también las secciones `## Tasks` / `## Retro` que siguen a un retro en archivos ya escritos.

## Acceptance criteria

- [x] `learningsTail` descarta un retro automático completo, incluidas sus secciones `## Tasks` y `## Retro`, y conserva las reglas que vienen después
- [x] `appendLearningsSection` anida los encabezados del cuerpo (`#` → `###`, `##` → `####`) para que la sección quede como un solo bloque `##`
- [x] Tests de regresión para ambos casos; el brief de este repo ya no muestra `### Backlog (0)` ni `_none_`
