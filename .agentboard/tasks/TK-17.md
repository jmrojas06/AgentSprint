## Description

Al cerrar un sprint, generar automáticamente una retrospectiva: resumen de tareas completadas vs pendientes, puntos quemados, bloqueos encontrados, y guardar las conclusiones clave en la memoria de aprendizajes (.agentboard/learnings.md). Así cada sprint cierra capturando conocimiento reutilizable que se inyecta en specs futuras.

Implementación: hook en setSprintStatus('closed') o comando dedicado `agentboard retro`, combinando buildSprintReport + learnings_append.

## Acceptance criteria

- [x] Al cerrar un sprint (UI, CLI o sprint_close MCP) se genera automáticamente el reporte con buildSprintReport
- [x] El resumen retro se agrega a .agentboard/learnings.md vía appendLearning con encabezado del sprint y fecha
- [x] Tool MCP sprint_retro que devuelve el reporte + lista de aprendizajes sugeridos para revisar
- [x] Opción --no-retro para desactivar la generación automática
- [x] Tests que validan que cerrar sprint crea la entrada en learnings.md
